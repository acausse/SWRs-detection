# Citation

If you use this SWR detection approach in a scientific analysis, cite the paper
that describes the multi-stage methodology:

> Causse, A. A., Curot, J., Lopes-dos-Santos, V., et al. (2026).
> A learning-evoked slow-oscillatory architecture paces population activity
> for offline reactivation across the human medial temporal lobe.
> *Neuron*, **114**, 3786-3798.
> https://doi.org/10.1016/j.neuron.2026.05.004

Relevant **STAR Methods** section: "Detection of hippocampal ripples",
including "Loose detection of putative ripple events" and "Template matching
and white-matter control".

Template generation is documented in the paper but is **not** implemented in
this repository. Supply precomputed, validated templates.

The repository owner may add a separate software citation or `CITATION.cff`
with verified authorship and version metadata before release.
